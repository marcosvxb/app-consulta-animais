APP CONSULTA BOVINOS - PWA OFFLINE ROBUSTA

O que mudou:
- Instala no iPhone e Android como PWA.
- Salva dados.csv no IndexedDB do aparelho.
- Funciona offline mesmo depois de fechar o navegador.
- Tem botão Atualizar base.
- Quando online, o usuário toca em Atualizar base para baixar a base nova.
- Quando offline, usa a última base salva.

Como publicar:
1. Extraia este ZIP.
2. GitHub > app-consulta-animais2.
3. Add file > Upload files.
4. Arraste todos os arquivos extraídos.
5. Confirme substituição.
6. Commit changes.
7. Aguarde o Vercel publicar.
8. No celular, abra o site e toque em Atualizar base.
9. Instale:
   - iPhone: Safari > Compartilhar > Adicionar à Tela de Início.
   - Android: Chrome > menu > Instalar app ou Adicionar à tela inicial.

Importante:
- O primeiro uso precisa de internet para salvar a base.
- Depois disso, funciona offline com a última base salva.
